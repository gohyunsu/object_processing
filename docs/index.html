100 Everyday Objects

Our object library contains 100 everyday household objects spanning seven material types — plastic, metal, wood, paper, rubber, glass, and sponge. From lightweight containers to heavy kitchen tools, the collection captures the diversity of objects encountered in real-world manipulation. More than 80% of the objects are commercially available IKEA products, enabling reproducible research.

The Complete AutoDex Object Library

Explore the full object library through an interactive 3D browser. Every object can be inspected together with the complete set of robot-ready assets generated by our processing pipeline.

Robot-Ready Assets for Every Object

Each object is distributed with a complete set of assets for visualization, simulation, and robotic manipulation — not just a textured mesh, but also collision geometry, processed meshes, physical metadata, and simulator descriptions.

All examples below are rendered directly from the generated assets of a single object (French's Mustard) in one of its stable tabletop poses.

Textured Mesh

High-resolution scanned mesh (.glb) with photorealistic textures.

Collision Mesh

Convex decomposition (CoACD) optimized for efficient and stable physics simulation.

Watertight Mesh

Closed, manifold geometry suitable for geometry processing and simulation.

Simplified Mesh

Decimated to approximately 2k vertices for efficient rendering and visualization.

Oriented Bounding Box

Object-aligned bounding box with mass properties and center of mass.

Symmetry Axes

Automatically detected rotational symmetry annotations.

Stable Tabletop Poses

Computed stable resting poses for tabletop manipulation.

Simulator Descriptions

Ready-to-use URDF and MJCF descriptions for MuJoCo and other robotics simulators.
